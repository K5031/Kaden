## macOS support

Discussed with the user 2026-11-26. `docs/getting-started.md` says macOS "should work but
is untested"; in practice the file tools fail there (Top tier 1).

### Approach
Industry practice (Claude Code, Codex CLI, Gemini CLI, browsers): each OS's native
mechanism behind one interface, not one cross-platform tool. Keep the OS split in one
place per capability:
- One `find()` per capability, called once at startup, returns a backend or `None`.
  `sys.platform` appears only inside these functions.
- The interface states what the rest of the code needs (policy), not how an OS does it.
- Probe for the capability (run `true` in the sandbox, as `_bwrap()` does), don't infer
  it from the OS name. `None` is a real result: commands ask.
- Each backend tested on its own CI runner (skipped when its tool is missing); shared
  code tested against a fake backend.
- Where one portable call exists, no interface at all.

No change to the Tools contract in `api.py`: `confined()` / `ToolContext.confined` already
say only "this call touches nothing outside the work folder"; the sandbox and the
screenshot program are private to `tools/shell_files/`.

### Steps
1. **File tools** (no decision needed). Replace the `/proc/self/fd` check in `_open`
   (`tools/shell_files/__init__.py:506`) with an `os.fstat(fd)` (st_dev, st_ino)
   comparison against the checked path; same code on both systems. Add a test that runs a
   confined Read/Write/Edit/Glob/Grep on any platform (the current suite didn't catch it).
2. **Sandbox** (open decision 3). Move `_sandbox`/`_bwrap` into
   `tools/shell_files/sandbox.py`: a `Sandbox` protocol
   (`wrap(command, root, granted) -> list[str]`), `Bubblewrap`, `Seatbelt`
   (`sandbox-exec` with a generated profile), `find()`. The Seatbelt profile must match
   the table in `notes/implemented/2026-11-10-free-in-the-work-folder.md` row by row:
   system folders readable; home, `/tmp`, the login session's services and the Keychain
   hidden except the work folder; writes only in the work folder, private tmp and granted
   paths; network as outside; secret-looking env vars removed. Write the Agent Note first
   (it changes the note's "Linux only" decision). Update `docs/settings.md:139`
   ("Without the sandbox, commands ask. That is the case on macOS").
3. **Screenshot** (open decision 4). `screen.py` only finds KDE's `spectacle`. Proposed:
   `screen.find()` → xdg-desktop-portal Screenshot on Linux (GNOME and KDE), 
   `screencapture -x` on macOS (needs Screen Recording permission; without it macOS
   returns only the wallpaper, report that), else `None`.
4. **Credential patterns**. Add macOS forms to `CREDENTIALS` in `runtime/review.py:75`
   (`~/Library/Keychains`, `security find-generic-password` / `dump-keychain`). One list
   for both systems.
5. **CI**. All jobs in `.github/workflows/` run on ubuntu. Add a `macos-latest` test job.
6. **Desktop bundle** (later). Info.plist needs `NSMicrophoneUsageDescription` for voice;
